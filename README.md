# Telecom Data Pipeline

**Apache Spark (PySpark) | AWS MWAA (Apache Airflow) | Amazon EMR | Amazon S3 | Amazon Redshift | Terraform**

A batch data pipeline for telecom network analytics, built with AWS, PySpark, and Airflow. It transforms raw data into analytics-ready datasets using a Bronze–Silver–Gold architecture, with Terraform-managed infrastructure and GitHub Actions CI/CD.

# Business Problem

A telecommunications company collects daily batches of mobile network measurements from multiple cities, devices, and network types. The company needs an automated, scalable data pipeline that validates and transforms raw measurements into structured, analytics-ready datasets.
